# punjab-flood-mapping-2025
Flood extent mapping and assessment across Punjab, Pakistan using Sentinel-1 SAR and Google Earth Engine.

About The Project:
Monsoon-induced flooding presents a recurrent and critical threat to infrastructure, agriculture, and human lives across Punjab, Pakistan. Traditional optical satellite monitoring frequently fails during heavy flood events due to persistent cloud cover. To overcome this limitation, this project leverages Synthetic Aperture Radar (SAR) data from the Sentinel-1 mission. Because SAR microwaves penetrate cloud cover and operate independently of solar illumination, this workflow delivers reliable, high-resolution surface water mapping during active precipitation events.
